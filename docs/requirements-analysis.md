# Requirements Analysis

1. **Problem:** Students need an easy way to understand spending and compare it with a monthly budget.
2. **Target users:** Students managing everyday expenses.
3. **Functional requirements:** Add and delete expenses, select a month, filter categories, calculate totals, set monthly budgets, and retain entries after refresh.
4. **Required inputs:** Description, amount in pesos, category, date, selected month, and monthly budget.
5. **Expected outputs:** Expense list, monthly total, budget, remaining amount or overspending, category totals, and success or error messages.
6. **Proposed features:** Validated expense form, monthly summary, category filter, confirmed deletion, and localStorage persistence.
7. **Tools and technologies:** HTML, CSS, vanilla JavaScript, browser localStorage, and Codex for implementation assistance. Git and GitHub can be used for practice version control.

The supplied document contains general exam instructions but no specific student expense scenario. These are practice requirements inferred from the user's request.
